# Postgraduate Dissertation 🎓

> **⚠️ Status:** Work in Progress. The codebase, literature review, and documentation are currently under active development.

## Overview
This repository contains the codebase, research materials, and LaTeX source files for my Postgraduate Dissertation. The research broadly focuses on advanced Reinforcement Learning (RL) concepts, specifically exploring:
- Visual causal chains and event detection
- Credit assignment in long-horizon environments and sparse reward settings
- Vision-based event memory and episodic memory
- Reward redistribution and return decomposition

## Current Progress
- **Literature Review Pipeline:** Developed an automated Python data collection script (`fetch.py`) utilizing the Semantic Scholar API to scrape, filter, and aggregate hundreds of relevant academic papers based on targeted queries.
- **Documentation Setup:** Established a robust LaTeX build environment with automated PDF compilation and organization into specific output directories for drafting the dissertation proposals and final document.
- **Environment Configuration:** Set up Python virtual environments for dependency management and configured project-specific Git tracking.
